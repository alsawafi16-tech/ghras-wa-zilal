# غرس وظلال
تطبيق Android لمشروع غرس وظلال.

## المزايا
- أقسام التشجير ومشروع 200 نخلة والتجارب الزراعية وشركة قطاف.
- طرق الري والطاقة المتجددة.
- إضافة وتعديل وحذف الزيارات والمصروفات.
- إرفاق صورة أو فيديو وحفظ البيانات محليًا على الهاتف.
- الجهات الداعمة.

## بناء APK عبر EAS
1. npm install
2. npx eas-cli login
3. npx eas-cli build -p android --profile preview
