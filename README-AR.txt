غرس وظلال — نسخة Android
========================
هذه الحزمة مبنية حول app.js المرفق وتعمل باستخدام Capacitor، ولا تحتاج Expo Go.

أسهل طريقة لإنشاء APK على Windows:
1) ثبّت Node.js (إصدار LTS) و Android Studio.
2) افتح Android Studio مرة واحدة وأكمل تثبيت Android SDK.
3) فك ضغط هذا الملف في الكمبيوتر.
4) شغّل BUILD-ANDROID.bat.
5) انتظر حتى يكتمل البناء.
6) سيظهر الملف Ghars-Wa-Zilal.apk داخل نفس المجلد.
7) أرسل APK إلى هاتف Android وافتحه ثم وافق على التثبيت من هذا المصدر.

للتطوير عبر Android Studio:
- npm install
- npx cap add android   (أول مرة فقط)
- npx cap sync android
- npx cap open android

ملاحظات:
- بيانات التطبيق محفوظة محلياً على الجهاز.
- استخدم النسخ الاحتياطي داخل لوحة المشرف قبل حذف التطبيق أو بياناته.
- عند أول دخول للمشرف سيطلب التطبيق إنشاء كلمة مرور لا تقل عن 8 أحرف.
